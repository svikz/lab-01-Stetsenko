# Дизайн-система та веб-сайт: Алгоритми та структури даних

Проєкт розроблено в рамках лабораторних робіт з дисципліни веб-дизайну та розробки. 
Сайт містить навчальні матеріали про алгоритми, порівняльні таблиці та форму заявки, а також окрему сторінку-довідник дизайн-системи.

## Автор
* **Студентка:** Вікторія Стеценко
* **Група:** КН-21

## Стек технологій
* HTML5 (Семантична розмітка, доступність за стандартами WCAG/POUR)
* CSS3 (Модульна сітка Grid, Flexbox, Custom Properties/Токени, Mobile-first)
* Дизайн та прототипування: Figma

## Структура проєкту
* `/css` — таблиці стилів (основний файл `style.css` із токенами в `:root`).
* `/fonts` — локально підключені шрифти (Roboto, Fira Code).
* `/img` — оптимізовані зображення.
* `index.html` — головна сторінка сайту.
* `styleguide.html` — довідник дизайн-системи (компоненти та токени).
* `README.md` — документація проєкту.

## Особливості реалізації
1. **Дизайн-система:** Усі значення кольорів, відступів, тіней та шрифтів винесені в CSS-змінні (токени).
2. **Адаптивність:** Макет побудовано на 12-колонковій сітці, яка адаптується для планшетів (8 колонок) та мобільних пристроїв (4 колонки).
3. **Доступність:** Сайт успішно проходить перевірку WAVE (0 помилок), підтримує навігацію клавіатурою (видимий `:focus-visible`) та має правильну ієрархію заголовків.
